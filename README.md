# Mnemonica

모바일에서 Mnemonica Stack 52장을 학습하고 외우는 웹 앱입니다.

## 기능

- 카드 → 숫자, 숫자 → 카드, 혼합 플래시 카드
- 좌우 스와이프 암기 기록과 틀린 카드 자동 재등장
- 13장 단위 구간 학습과 앞뒤 카드 연결 보기
- 10·20·52문제 객관식 시험과 오답 재시험
- 전체 스택 검색·무늬 필터·암기 상태 관리
- 로그인 없이 브라우저에 진도, 연속 학습일, 정답률 저장
- 모바일 터치 및 안전 영역 대응

## 로컬 실행

```bash
pnpm install
pnpm dev
```

`main` 브랜치에 푸시하면 GitHub Actions가 정적 앱을 빌드해 GitHub Pages에 배포합니다.
